# @amlplugins/vercel-ai-amazon-bedrock

Native `@ai-sdk/amazon-bedrock` SDK re-exported under the `@amlplugins` namespace.

> Vercel AI SDK Amazon Bedrock provider — Anthropic/Llama/Mistral/Titan on AWS Bedrock Converse and Runtime.

## Install

```bash
npm install @amlplugins/vercel-ai-amazon-bedrock
```

## Use

```ts
import { /* named exports from @ai-sdk/amazon-bedrock */ } from "@amlplugins/vercel-ai-amazon-bedrock";
// or
import sdk from "@amlplugins/vercel-ai-amazon-bedrock";
```

This package additionally re-exports `ai` under the `secondary` namespace.

Built and published by GitHub Actions on every push to `main`.

Part of the amlplugins family — see https://github.com/amlplugins.
